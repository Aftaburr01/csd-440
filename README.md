## 🌐 Web Application Development

Coursework demonstrates how PHP can receive information from an HTML form, process that information on the server, and return a dynamically generated response to the user.

This provides a foundation for understanding the request/response lifecycle used by server-side web applications.

---

## 🧩 Key Concepts

### Dynamic Pages

PHP code is embedded into web pages to generate content dynamically rather than relying only on static HTML.

### Form Processing

Applications collect user input through HTML forms and process submitted values with PHP.

### Separation of Concerns

HTML, CSS, and server-side processing are organized so that presentation and application logic can be maintained independently where practical.
